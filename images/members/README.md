# MCCI Lab 成员照片

请将成员头像上传到本目录，推荐使用 JPG 格式、正方形构图、500×500 像素左右，每张尽量不超过 300 KB。

文件名应与 `_members/` 中对应 Markdown 文件的基本名称一致，例如：

- `_members/li-jingzhi.md` → `images/members/li-jingzhi.jpg`
- `_members/chen-huilin.md` → `images/members/chen-huilin.jpg`

**注意：** 目前网页通过成员 Markdown 文件里的 `image` 字段读取照片；上传后需要在对应文件的 YAML 顶部添加 `image: /images/members/文件名.jpg`，待后续部署自动匹配功能后才能省略此步骤。

为保护个人隐私，只上传本人同意公开的照片。
